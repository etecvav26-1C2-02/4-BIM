Política de privacidade

Como este projeto acadêmico fictício trata as informações preenchidas nos formulários.

Última atualização: outubro de 2026.

Este site é uma demonstração

O Patas Unidas é um projeto acadêmico fictício. Nenhum formulário envia dados para servidores, bancos de dados ou serviços externos. Todas as informações digitadas permanecem apenas no navegador durante a interação.

1. Informações coletadas

Os formulários de contato e voluntariado solicitam nome, e-mail, telefone, cidade, assunto, área de interesse, disponibilidade e mensagem. Esses campos existem apenas para demonstrar boas práticas de formulário, validação e acessibilidade.

2. Finalidade

Em um cenário real, os dados seriam utilizados para responder à solicitação, organizar o processo de adoção ou voluntariado e manter contato sobre campanhas. Neste projeto, nenhuma finalidade é efetivamente executada.

3. Armazenamento e envio

Não há backend, banco de dados ou envio por e-mail. O JavaScript apenas simula o envio no próprio navegador e exibe uma mensagem de confirmação. Nenhum dado é armazenado em localStorage, cookies ou qualquer outro mecanismo persistente.

4. Cookies e rastreamento

O site não utiliza cookies de análise, publicidade ou rastreamento. As imagens são armazenadas localmente no projeto, e os scripts são próprios, em JavaScript puro.

5. Compartilhamento

Como não há coleta real de dados, não existe compartilhamento com terceiros. Links externos, como redes sociais e mapas, são apenas exemplos e possuem suas próprias políticas.

6. Direitos do titular

Em uma aplicação real, o titular teria direito de solicitar acesso, correção, exclusão e informações sobre o tratamento dos dados. Como esta é uma demonstração, não há dados armazenados para consultar ou excluir.

7. Segurança

O projeto evita bibliotecas externas de JavaScript, não processa pagamentos e não coleta dados sensíveis. Em uma versão de produção, seriam necessários servidor seguro, criptografia, controle de acesso e conformidade com a LGPD.

8. Contato

Dúvidas sobre este projeto podem ser direcionadas ao canal fictício contato@patasunidas.org.br ou à página de contato.
